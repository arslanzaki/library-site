# Digital University Library Website

A complete, responsive website for the Digital University Library built with HTML, CSS, and JavaScript.

## Features

- **5 Pages**: Home, Booklist, Library Rules, Timings, and Book Request Form
- **Responsive Design**: Optimized for mobile, tablet, and desktop devices
- **Modern Design**: Professional appearance with deep blue (#003366), white (#FFFFFF), and gold (#FFD700) color scheme
- **Interactive Elements**: 
  - Searchable and sortable booklist table
  - Form validation with success alerts
  - Hover effects and smooth transitions
- **Accessibility**: ARIA labels, semantic HTML5, and keyboard navigation support

## File Structure


## Page Details

### Home (index.html)
- Hero section with welcoming message
- Featured books section with placeholder images
- Mission statement
- Call-to-action button linking to booklist

### Booklist (booklist.html)
- Searchable table with 14 sample books
- Sortable columns (Title, Author, Genre, Year, Availability)
- Real-time search filtering
- Responsive table design

### Library Rules (rules.html)
- 10 numbered rules with detailed descriptions
- Visual icons and hover effects
- Contact information section

### Timings (timings.html)
- Regular operating hours
- Special hours and holiday information
- Service availability details
- Emergency contact information

### Book Request Form (request.html)
- Complete form validation
- Required fields: Full Name, Email, Book Title, Reason
- Optional: Student ID
- Success alert on submission
- Step-by-step process explanation
